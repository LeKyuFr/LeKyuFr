- 📊 **5 types de graphiques** (Bar, Line, Pie, Scatter, Heatmap)
- ⚡ **Données temps réel** avec simulation WebSocket
- 🎯 **Canvas personnalisé** pour les heatmaps
- 📱 **Design responsive** avec thèmes sombre/clair
- 🚀 **Architecture ES6+** moderne et modulaire

**Tech Stack:** `Vite` `Chart.js` `Canvas API` `ES6 Modules` `Tailwind CSS`

- 🔍 **SEO optimisé** avec meta tags dynamiques

**Tech Stack:** `Next.js` `TypeScript` `Framer Motion` `Tailwind CSS`
